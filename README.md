## O que o projeto faz

Ordena a mesma coleção por dois métodos, Insertion Sort e Merge Sort, mostrando o
resultado, os passos intermediários e a contagem de comparações de cada um.


## Como executar

Abra o terminal na pasta do projeto e rode:

- Demonstração: `py src/demo.py` 
- Testes: `py src/test_ordenacao.py` 

## Entrada de exemplo

[ajustar quando o demo.py estiver pronto]

Coleção usada na demonstração: `[38, 27, 43, 3, 9, 82, 10]`

Saída esperada: a mesma coleção ordenada, `[3, 9, 10, 27, 38, 43, 82]`, pelos dois métodos.

## Estrutura

- `src/ordenacao.py`: Insertion Sort e Merge Sort
- `src/demo.py`: programa de demonstração
- `src/test_ordenacao.py`: testes (vazia, um elemento, já ordenada, ordem inversa, repetidos)
- `docs/slide.PDF`: relatório técnico
- `docs/relatorio.PDF`: declaração de uso de IA
- `evidencias/`: prints e saídas das execuções
